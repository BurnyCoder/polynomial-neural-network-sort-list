This document details the exact mathematics of the strictly pure Polynomial Neural Networks (PNNs) implemented in `pnn-sort`, contrasts them side by side with classic neural networks (`ReLU`/`GELU` MLPs and differentiable sorting networks), and works through every equation with concrete plugged-in numbers and full algebraic steps.

Every pure-polynomial model in this repository (`is_pure_polynomial = True`) is mechanically verified via `torch.fx.symbolic_trace` in [`audit.py`](../src/pnn_sort/audit.py) to execute **exclusively** additions, subtractions, multiplications, linear maps, non-negative integer powers, and constant scalar scaling—with zero `ReLU`, `GELU`, `sigmoid`, `tanh`, `atan`, `max`/`min`, division by tensors, or normalization layers.

## 1. Mathematical Formulation of the Polynomial Neural Network Used (`PolySortNet`)

Given an unsorted input vector $x^{(0)} = x \in [-1, 1]^n$, exact sorting computes the order-statistics map $S(x) = (x_{(1)}, \dots, x_{(n)})$ by chaining two-element compare-and-swap (CAS) gates:

$$\min(a, b) = \frac{a + b}{2} - \frac{b - a}{2}\operatorname{sign}\!\left(\frac{b - a}{2}\right), \qquad \max(a, b) = \frac{a + b}{2} + \frac{b - a}{2}\operatorname{sign}\!\left(\frac{b - a}{2}\right).$$

Because $\operatorname{sign}(\cdot)$ is discontinuous (and $|a - b|$ has a sharp corner at $a = b$), **`PolySortNet`** ([`sorters.py`](../src/pnn_sort/models/sorters.py)) replaces $\operatorname{sign}(\cdot)$ with a **learned composite odd Chebyshev polynomial** embedded inside a fixed sorting-network topology (Batcher's Bitonic or Odd-Even Merge network, [Batcher, 1968](https://doi.org/10.1145/1468075.1468121); [`wiring.py`](../src/pnn_sort/models/wiring.py)).

### 1.1 Step A: Sorting-Network Stage ($t = 0, \dots, \ell - 1$)

For Bitonic sort, the number of parallel stages is $\ell = \frac{1}{2}p(p+1)$ with $p = \lceil \log_2 n \rceil$ ($\ell = 1$ for $n=2$, $\ell = 3$ for $n=4$, $\ell = 6$ for $n=8$, $\ell = 10$ for $n=16$). Each stage $t$ uses fixed constant routing matrices $S_a^{(t)}, S_b^{(t)} \in \{0, 1\}^{K_t \times n}$ and $C_{\min}^{(t)}, C_{\max}^{(t)} \in \{0, \tfrac{1}{2}, 1\}^{n \times K_t}$ (column-vector convention matching PyTorch's `F.linear` in [`sorters.py`](../src/pnn_sort/models/sorters.py)):

$$a^{(t)} = S_a^{(t)} x^{(t)}, \qquad b^{(t)} = S_b^{(t)} x^{(t)},$$

$$\mu^{(t)} = \frac{a^{(t)} + b^{(t)}}{2}, \qquad \Delta^{(t)} = \frac{b^{(t)} - a^{(t)}}{2} \in [-1, 1]^{K_t},$$

$$\widehat{\min}^{(t)} = \mu^{(t)} - \Delta^{(t)} \odot s_\theta^{(t)}\!\left(\Delta^{(t)}\right), \qquad \widehat{\max}^{(t)} = \mu^{(t)} + \Delta^{(t)} \odot s_\theta^{(t)}\!\left(\Delta^{(t)}\right),$$

$$x^{(t+1)} = C_{\min}^{(t)} \widehat{\min}^{(t)} + C_{\max}^{(t)} \widehat{\max}^{(t)}.$$

- **Shared-Gate (`polysort_shared`):** All $\ell$ stages share one comparator $s_\theta^{(t)} \equiv s_\theta$, enabling **zero-shot list-length generalization** to arbitrary $n$ via `for_length()`.
- **Stage-Adaptive (`polysort_adaptive`):** Each stage $t$ learns its own polynomial coefficients $\theta^{(t)}$ tailored to its intermediate gap distribution.

### 1.2 Step B: Fixed-Point Odd Chebyshev Composite Sign (`CompositePolySign`)

Applied elementwise to $u = \Delta^{(t)}$ ([`poly_blocks.py`](../src/pnn_sort/models/poly_blocks.py)), $s_\theta$ composes $L$ residual odd Chebyshev blocks ($z_0 = u$, $s_\theta(u) = z_L$):

$$z_k = h_k(z_{k-1}) = z_{k-1} + z_{k-1}\!\left(1 - z_{k-1}^2\right) \sum_{j=0}^{m-1} c_{k,j}\, T_{2j}(z_{k-1}), \qquad k = 1, \dots, L,$$

where the even Chebyshev polynomials of the first kind are evaluated strictly via polynomial recurrence (`chebyshev_even_basis` in [`poly_blocks.py`](../src/pnn_sort/models/poly_blocks.py)):

$$T_0(u) = 1, \qquad T_2(u) = 2u^2 - 1, \qquad T_{2j}(u) = 2 T_2(u) T_{2j-2}(u) - T_{2j-4}(u).$$

**Explicit expanded forms ($L = 3$):**
- **Cubic block ($m = 1$, block degree $d = 2m + 1 = 3$, comparator degree $D_s = 3^3 = 27$):**
  $$h_k(u) = u + c_{k,0}\,u(1 - u^2) = (1 + c_{k,0})\,u - c_{k,0}\,u^3.$$
  Setting $c_{k,0} = \frac{1}{2}$ recovers the analytical CKKS polynomial $f_1(u) = \frac{3}{2}u - \frac{1}{2}u^3$ of [Cheon, Kim & Kim (ASIACRYPT 2020)](https://eprint.iacr.org/2019/1234). In Stage 4A ([`stage-4a-controls-and-main/learnings.md`](../reports/experiments/stage-4a-controls-and-main/learnings.md)), gradient descent on `main_polysort_shared_n8_s42` discovers a **3-parameter decreasing-gain schedule** $(c_{1,0}, c_{2,0}, c_{3,0}) = (1.4017, 0.8521, 0.7530)$ (exact float32: `1.401746, 0.852099, 0.752972`):
  $$h_1(u) = 2.4017u - 1.4017u^3, \quad h_2(u) = 1.8521u - 0.8521u^3, \quad h_3(u) = 1.7530u - 0.7530u^3.$$
- **Quintic block ($m = 2$, block degree $d = 5$, comparator degree $D_s = 5^3 = 125$):**
  $$h_k(u) = (1 + c_{k,0} - c_{k,1})\,u + (3c_{k,1} - c_{k,0})\,u^3 - 2c_{k,1}\,u^5.$$
  Setting $(c_{k,0}, c_{k,1}) = (\frac{11}{16}, -\frac{3}{16})$ recovers Cheon et al.'s $f_2(u) = \frac{15}{8}u - \frac{10}{8}u^3 + \frac{3}{8}u^5$. With only **6 learnable parameters** (`main_polysort_shared_m2_n8_s42`), this reaches `0.0079` MAE on $n = 8$ and `0.0200` MAE zero-shot on $n = 128$ ([`stage-4a-controls-and-main/experiment.md`](../reports/experiments/stage-4a-controls-and-main/experiment.md)).

**Guaranteed algebraic invariants (for *any* $\theta$):**
1. **Odd symmetry & fixed points:** $s_\theta(-u) = -s_\theta(u)$, $s_\theta(0) = 0$, and $s_\theta(\pm 1) = \pm 1$ identically because $u(1 - u^2)$ vanishes at $u \in \{-1, 0, +1\}$.
2. **Exact sum conservation:** $\widehat{\min} + \widehat{\max} = (\mu - \Delta s_\theta(\Delta)) + (\mu + \Delta s_\theta(\Delta)) = 2\mu = a + b$, so $\sum_i \hat{y}_i = \sum_i x_i$ (verified to `~2.2e-16` in float64).
3. **Exact shift equivariance:** Shifting $x \mapsto x + c\mathbf{1}$ leaves $\Delta = \frac{(b+c)-(a+c)}{2}$ invariant and shifts $\mu \mapsto \mu + c$, so $f_\theta(x + c\mathbf{1}) = f_\theta(x) + c\mathbf{1}$ identically (verified to `~7e-14` for $c = 100$ in float64).
4. **Exponential degree compression:** Each stage has degree $D_s + 1$, giving an overall multivariate polynomial degree upper bound of $(D_s + 1)^\ell$ (e.g., $28^6 \approx 4.82 \times 10^8$ for $m=1, n=8$ and $126^6 \approx 4.00 \times 10^{12}$ for $m=2, n=8$) using only $O(\ell \cdot L \cdot m)$ multiplications per wire.

### 1.3 Other Pure PNN Formulations in This Repository

- **`PolyMLP`** ([Kileel, Trager & Bruna, NeurIPS 2019](https://arxiv.org/abs/1905.12207); [`sorters.py`](../src/pnn_sort/models/sorters.py)): Dense affine layers with per-neuron learnable degree-3 Chebyshev activations:
  $$h^{(t)} = \phi_{\text{Cheb}}^{(t)}\!\left(W^{(t)} h^{(t-1)} + b^{(t)}\right), \qquad \phi_{\text{Cheb}, i}^{(t)}(z) = \sum_{k=0}^{3} c_{k,i}^{(t)} T_k(z).$$
- **`PiNetSorter` (Pure NCP-Skip)** ([Chrysos et al., IEEE TPAMI 2021](https://arxiv.org/abs/2006.13026), Eq. 10, strictly without BatchNorm or `tanh`; [`poly_blocks.py`](../src/pnn_sort/models/poly_blocks.py)): Nonlinearity comes exclusively from Hadamard products ($\odot$) of linear projections:
  $$x_1 = (A_1 z) \odot b_1, \qquad x_k = (A_k z) \odot (S_k x_{k-1} + b_k) + V_k x_{k-1} \;\; (k = 2,\dots,N), \qquad \text{out} = C x_N + \beta.$$
- **`PolyPairwiseRank`** ([Mazzone et al., USENIX Security 2025](https://arxiv.org/abs/2412.15126); [`sorters.py`](../src/pnn_sort/models/sorters.py)): Constant $O(1)$ comparison depth via all-pairs $C_{ij} = \frac{1 + s_{\text{cmp}}((x_j - x_i)/2)}{2}$, exact quadratic tie indicator $E_{ij} = 4 C_{ij}(1 - C_{ij})$, tie-resolved ranks $r_j = \sum_i C_{ij} + \sum_{i \le j} E_{ij} - \frac{1}{2}\sum_i E_{ij}$, and parallel polynomial rank extraction $\hat{y}_k = \sum_j W_{jk} x_j$.
- **`DeepSetsPoly`** ([Zaheer et al., NeurIPS 2017](https://arxiv.org/abs/1703.06114); [Wagstaff et al., JMLR 2022](https://arxiv.org/abs/1901.09006); [`sorters.py`](../src/pnn_sort/models/sorters.py)): Permutation-invariant Chebyshev moment pooling $\frac{1}{n}\sum_{i=1}^n \phi([T_1(x_i), \dots, T_K(x_i)]^\top)$ into latent width $\ge \max(64, 4n)$, decoded by two `PureNCPSkipBlock`s.

## 2. How the Classic ReLU MLP Produces Two Sorted Outputs ($\hat{y} = W^{(2)} h$)

Because list sorting maps an unsorted $n$-element vector $x \in \mathbb{R}^n$ to a sorted $n$-element vector $\hat{y} \in \mathbb{R}^n$, the final linear layer `nn.Linear(hidden_dim, n)` in [`ReLUMLPBaseline`](../src/pnn_sort/models/sorters.py) has **$n$ output rows**—one output neuron per sorted slot. For $n = 2$, $W^{(2)} \in \mathbb{R}^{2 \times 4}$ has **2 rows**, producing $\hat{y} = (\hat{y}_1, \hat{y}_2)^\top = (\widehat{\min}, \widehat{\max})^\top$.

Explicitly, on $x = (a, b)^\top = (0.8, -0.2)^\top$:

1. **Hidden layer ($\mathbb{R}^2 \to \mathbb{R}^4$):**
   $$z = W^{(1)} x = \begin{pmatrix} 0.5 & 0.5 \\ -0.5 & -0.5 \\ 0.5 & -0.5 \\ -0.5 & 0.5 \end{pmatrix} \begin{pmatrix} 0.8 \\ -0.2 \end{pmatrix} = \begin{pmatrix} 0.5(0.8) + 0.5(-0.2) \\ -0.5(0.8) - 0.5(-0.2) \\ 0.5(0.8) - 0.5(-0.2) \\ -0.5(0.8) + 0.5(-0.2) \end{pmatrix} = \begin{pmatrix} 0.3 \\ -0.3 \\ 0.5 \\ -0.5 \end{pmatrix},$$
   $$h = \operatorname{ReLU}(z) = \begin{pmatrix} \max(0,\, 0.3) \\ \max(0,\, -0.3) \\ \max(0,\, 0.5) \\ \max(0,\, -0.5) \end{pmatrix} = \begin{pmatrix} 0.3 \\ 0 \\ 0.5 \\ 0 \end{pmatrix}.$$
   Why 4 hidden neurons? Because ReLU zeros out negative values, a single ReLU layer uses pairs of opposite-sign neurons to preserve signed values and form absolute values:
   - $h_1 - h_2 = \operatorname{ReLU}\!\left(\frac{a+b}{2}\right) - \operatorname{ReLU}\!\left(-\frac{a+b}{2}\right) = \frac{a+b}{2} = \mu$,
   - $h_3 + h_4 = \operatorname{ReLU}\!\left(\frac{a-b}{2}\right) + \operatorname{ReLU}\!\left(\frac{b-a}{2}\right) = \frac{|a-b|}{2} = |\Delta|$.

2. **Output layer ($\mathbb{R}^4 \to \mathbb{R}^2$, where the two outputs originate):**
   $$\hat{y} = \begin{pmatrix} \hat{y}_1 \\ \hat{y}_2 \end{pmatrix} = W^{(2)} h = \begin{pmatrix} 1 & -1 & -1 & -1 \\ 1 & -1 & 1 & 1 \end{pmatrix} \begin{pmatrix} 0.3 \\ 0 \\ 0.5 \\ 0 \end{pmatrix} = \begin{pmatrix} (1)(0.3) + (-1)(0) + (-1)(0.5) + (-1)(0) \\ (1)(0.3) + (-1)(0) + (1)(0.5) + (1)(0) \end{pmatrix} = \begin{pmatrix} -0.2000 \\ 0.8000 \end{pmatrix}.$$
   - **Row 1 of $W^{(2)}$** computes $(h_1 - h_2) - (h_3 + h_4) = \mu - |\Delta| = \min(a, b) = -0.2000$.
   - **Row 2 of $W^{(2)}$** computes $(h_1 - h_2) + (h_3 + h_4) = \mu + |\Delta| = \max(a, b) = 0.8000$.

## 4. Core Geometric & Mechanistic Takeaways

Comparing how each family approximates the absolute half-difference $|\Delta|$ inside a single comparison gate summarizes the entire trade-off in three lines:

- **Classic ReLU neuron:** $|\Delta| = \operatorname{ReLU}(\Delta) + \operatorname{ReLU}(-\Delta)$ — *exact piecewise-linear corner* via branching $\max(0, \cdot)$.
- **Classic smooth differentiable sorter (`DiffSort`):** $|\Delta| \approx \Delta \cdot \tanh(\beta\Delta)$ (or $\frac{2}{\pi}\Delta\arctan(2\beta\Delta)$) — *bounded everywhere* via transcendental `exp`/`atan`, sharpening toward exact $\min/\max$ as $|\Delta| \to \infty$.
- **Pure Polynomial Neural Network (`PolySortNet`):** $|\Delta| \approx \Delta \cdot (h_L \circ \dots \circ h_1)(\Delta)$ with $h_k(z) = z + z(1 - z^2)\sum_{j=0}^{m-1} c_{k,j} T_{2j}(z)$ — *strictly $\{+, -, \times\}$ only* (CKKS FHE-compatible).

Three mechanistic phenomena stand out directly from the worked numbers:
1. **Controlled intermediate overshoot (Row 1):** On $\Delta = -0.5$, `PolySortNet` Layer 1 intentionally pushes $z_1 = -1.0256$ slightly past $-1$, then Layer 2 pulls it back to $-0.9803$ because $1 - z_1^2 = -0.0519 < 0$ reverses the restoring term's sign. That oscillation is how 3 learned parameters reach `0.0046` error here (`0.00091` for 6-param quintic `m=2`).
2. **Smooth rounding vs. exact kink (Row 3):** Near a tie $(0.31, 0.29)$, `ReLU` hits the sharp corner with `0.0000` error, whereas every $C^\infty$ smooth approximator (`PolySortNet`, `GELU`, `DiffSort`) bends quadratically through $\Delta = 0$.
3. **Shift vs. scale OOD duality (Rows 6 & 7):** Adding $+100$ breaks unconstrained dense networks (`PolyMLP` explodes to `(-205.97, 375.95)`), whereas `PolySortNet` and `DiffSort` stay **exact** because $\Delta = (b - a)/2$ cancels the shift. Scaling by $4\times$ reverses the picture: `ReLU` and `DiffSort` become exact $(-0.8, 3.2)$, while `PolySortNet`'s $(1 - z^2)$ term turns negative for $|z| > 1$, driving cubic compounding ($-2 \to +6.41 \to -212.57 \to +7.23 \times 10^6$) unless bounded by a non-polynomial wrapper (`ScaleNormalizedPolySortWrapper` in [`sorters.py`](../src/pnn_sort/models/sorters.py)).
